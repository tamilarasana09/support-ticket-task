# Support Ticket App

A mobile-first responsive support ticket application built using **React, Node.js, Express, and PostgreSQL**.

## Features
- Create, view, and update support tickets.
- Mobile-first responsive design using Tailwind CSS.
- RESTful API backend with PostgreSQL.

## Tech Stack
- **Frontend:** React, Tailwind CSS, Axios
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **Bonus:** Docker, GitHub Actions, Deployment on Render & Vercel
